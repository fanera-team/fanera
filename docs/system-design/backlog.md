# Бэклог

> **Статус:** действует · **Обновлено:** 2026-11-12 · **Для кого:** вся команда

Задачи по вехам из [roadmap.md](roadmap.md). Задачи переносим в GitHub Issues/Projects: одна строка — одно issue.

**Бэкенд расписан подробно, фронтенд — крупными блоками.** Нарезку фронта делает фронт-команда, здесь отмечены только места, где фронт и бэк встречаются.

## Обозначения

| Поле | Значения |
|---|---|
| **Кто** | `бэк` · `фронт` · `вместе` (нужны оба, обычно на стыке контракта) · `devops` (скорее всего бэкендер) |
| **Размер** | **S** — до 1 дня · **M** — 2–3 дня · **L** — больше 3 дней: перед стартом делим на задачи поменьше |
| **Зависит от** | что должно быть смёрджено раньше |
| **Готово, когда** | критерии из [acceptance.md](acceptance.md) или конкретный результат. Общие требования к любому PR — [DoD в roadmap](roadmap.md#готовность-любой-задачи-dod) |

🔥 — задача на [критическом пути](roadmap.md#критический-путь): её начинаем первой. ❓ — зависит от [открытого вопроса](decisions.md#открытые-вопросы).
